# CSS Hero Section Project

This project is a simple web page made with `index.html` and `style.css`.

- `index.html` contains the page structure: header, navigation menu, content section, image, and button.
- `style.css` contains the design: colors, spacing, button style, image size, and layout.

## What this page does

- Shows a top navigation bar with links and a username button.
- Displays a hero section with a headline, paragraph, and call-to-action button.
- Includes an image on the right side.
- Uses CSS to make the page look nicer and keep the image inside its container.

## How to run it

- Use a code editor like VS Code.
- Open `index.html` with the Live Server extension to see changes immediately.

That is all. The page works by opening `index.html` in a browser and loading the styles from `style.css`.
